L’atome d’hydrogène

Équation de Schrödinger, orbitales, spectre et structure quantique

Un cours sur la résolution de l’atome d’hydrogène, les nombres quantiques, les orbitales et les transitions spectrales.

1 Du problème à deux corps à l’hamiltonien coulombien

L’atome d’hydrogène est le système lié le plus simple de la physique atomique : un proton et un électron interagissent par attraction électrostatique. Sa simplicité est pourtant trompeuse. Sa résolution fait apparaître simultanément la quantification de l’énergie, le moment cinétique orbital, les nombres quantiques, les orbitales tridimensionnelles et les raies spectrales.

Le modèle non relativiste de Schrödinger ne décrit pas toute la précision du spectre réel, mais il fournit l’ossature sur laquelle se construisent ensuite la structure fine, l’effet Zeeman, l’effet Stark, le décalage de Lamb et la structure hyperfine.

NoteCadre physique

Nous considérons d’abord :

  • un noyau ponctuel de charge \(+Ze\) et de masse \(m_N\) ;
  • un seul électron, de charge \(-e\) et de masse \(m_e\) ;
  • une interaction coulombienne instantanée ;
  • aucune interaction avec un champ extérieur ;
  • ni spin, ni correction relativiste, ni structure interne du noyau.

Le cas \(Z=1\) est l’hydrogène. Les mêmes équations avec \(Z>1\) décrivent les ions hydrogénoïdes tels que \(\mathrm{He}^+\) ou \(\mathrm{Li}^{2+}\).

1.1 Séparation du centre de masse

Notons \(\mathbf r_e\) et \(\mathbf r_N\) les positions de l’électron et du noyau. L’hamiltonien à deux corps est

\[ \widehat H =-\frac{\hbar^2}{2m_e}\nabla_e^2 -\frac{\hbar^2}{2m_N}\nabla_N^2 -\frac{Ze^2}{4\pi\varepsilon_0|\mathbf r_e-\mathbf r_N|}. \tag{1}\]

Il serait incorrect de fixer immédiatement le proton sans préciser l’approximation effectuée. Introduisons plutôt la position du centre de masse

\[ \mathbf R =\frac{m_e\mathbf r_e+m_N\mathbf r_N}{m_e+m_N}, \]

et la coordonnée relative

\[ \mathbf r=\mathbf r_e-\mathbf r_N. \]

Avec la masse totale \(M=m_e+m_N\) et la masse réduite

\[ \boxed{ \mu=\frac{m_em_N}{m_e+m_N}, } \tag{2}\]

l’énergie cinétique se sépare :

\[ -\frac{\hbar^2}{2m_e}\nabla_e^2 -\frac{\hbar^2}{2m_N}\nabla_N^2 =-\frac{\hbar^2}{2M}\nabla_R^2 -\frac{\hbar^2}{2\mu}\nabla_r^2. \]

L’hamiltonien devient donc

\[ \widehat H =\underbrace{-\frac{\hbar^2}{2M}\nabla_R^2}_{\widehat H_{\mathrm{CM}}} +\underbrace{\left( -\frac{\hbar^2}{2\mu}\nabla_r^2 -\frac{Ze^2}{4\pi\varepsilon_0r} \right)}_{\widehat H_{\mathrm{rel}}}. \tag{3}\]

Le centre de masse se comporte comme une particule libre. Toute la structure interne de l’atome est contenue dans le mouvement relatif, équivalent à celui d’une particule de masse \(\mu\) dans le potentiel

\[ V(r)=-\frac{Ze^2}{4\pi\varepsilon_0r}. \tag{4}\]

Comme \(m_N\gg m_e\), on a \(\mu\simeq m_e\), mais la masse réduite est nécessaire pour reproduire précisément les longueurs d’onde observées.

1.2 Échelles naturelles et unités atomiques

L’équilibre entre énergie cinétique quantique et attraction coulombienne fixe une longueur caractéristique. À l’échelle \(r=a\), on estime

\[ T\sim\frac{\hbar^2}{2\mu a^2}, \qquad |V|\sim\frac{Ze^2}{4\pi\varepsilon_0a}. \]

Pour \(Z=1\), l’égalité des ordres de grandeur conduit au rayon de Bohr corrigé de la masse réduite :

\[ \boxed{ a_\mu=\frac{4\pi\varepsilon_0\hbar^2}{\mu e^2}. } \tag{5}\]

Si l’on remplace \(\mu\) par \(m_e\), on obtient

\[ a_0=5{,}29\times10^{-11}\ \mathrm m. \]

L’échelle d’énergie associée est le hartree réduit

\[ E_{\mathrm h}^{(\mu)} =\frac{\mu e^4}{(4\pi\varepsilon_0)^2\hbar^2}. \]

Dans les unités atomiques, on pose \(\hbar=e=4\pi\varepsilon_0=m_e=1\). Pour un noyau infiniment lourd, l’hamiltonien relatif prend alors la forme très simple

\[ \widehat H=-\frac12\nabla^2-\frac{Z}{r}. \tag{6}\]

NoteRepère historique : du spectre à l’atome quantique

En 1885, Johann Balmer découvre une formule empirique pour plusieurs raies visibles de l’hydrogène. Johannes Rydberg la généralise ensuite en séries spectrales. En 1913, Niels Bohr reproduit ces fréquences en imposant des orbites quantifiées. La théorie de Schrödinger, en 1926, remplace définitivement ces orbites par des états ondulatoires tridimensionnels et explique naturellement les nombres quantiques.

1.3 Schéma énergétique du potentiel coulombien

Le potentiel tend vers \(-\infty\) lorsque \(r\to0\) et vers zéro lorsque \(r\to\infty\). Les états liés ont \(E<0\) ; le seuil \(E=0\) sépare le spectre discret du continuum d’ionisation.

def laguerre_associe(p, alpha, x):
    """Polynôme de Laguerre associé L_p^alpha(x), p entier positif ou nul."""
    x = np.asarray(x, dtype=float)
    if p == 0:
        return np.ones_like(x)
    if p == 1:
        return 1 + alpha - x
    L_avant = np.ones_like(x)
    L_courant = 1 + alpha - x
    for k in range(2, p + 1):
        L_suivant = ((2*k - 1 + alpha - x) * L_courant
                     - (k - 1 + alpha) * L_avant) / k
        L_avant, L_courant = L_courant, L_suivant
    return L_courant

def R_nl(n, l, r, Z=1.0):
    """Fonction radiale hydrogénoïde en unités a_mu = 1."""
    if not (n >= 1 and 0 <= l < n):
        raise ValueError("Il faut n >= 1 et 0 <= l < n.")
    r = np.asarray(r, dtype=float)
    rho = 2 * Z * r / n
    prefacteur = (2*Z/n)**1.5 * np.sqrt(
        math.factorial(n-l-1) / (2*n*math.factorial(n+l))
    )
    return (prefacteur * np.exp(-rho/2) * rho**l
            * laguerre_associe(n-l-1, 2*l+1, rho))

def probabilite_radiale(n, l, r, Z=1.0):
    return r**2 * np.abs(R_nl(n, l, r, Z))**2

def harmonique_reelle(type_orbitale, theta, phi):
    """Harmoniques sphériques réelles normalisées pour s, p et d."""
    if type_orbitale == "s":
        return np.ones_like(theta) / np.sqrt(4*np.pi)
    if type_orbitale == "pz":
        return np.sqrt(3/(4*np.pi)) * np.cos(theta)
    if type_orbitale == "px":
        return np.sqrt(3/(4*np.pi)) * np.sin(theta) * np.cos(phi)
    if type_orbitale == "py":
        return np.sqrt(3/(4*np.pi)) * np.sin(theta) * np.sin(phi)
    if type_orbitale == "dz2":
        return np.sqrt(5/(16*np.pi)) * (3*np.cos(theta)**2 - 1)
    if type_orbitale == "dxz":
        return np.sqrt(15/(4*np.pi)) * np.sin(theta)*np.cos(theta)*np.cos(phi)
    if type_orbitale == "dxy":
        return np.sqrt(15/(4*np.pi)) * np.sin(theta)**2*np.sin(phi)*np.cos(phi)
    if type_orbitale == "dx2y2":
        return np.sqrt(15/(16*np.pi)) * np.sin(theta)**2*np.cos(2*phi)
    raise ValueError("Type d'orbitale inconnu.")

2 Séparer les variables en coordonnées sphériques

Le potentiel Equation 4 ne dépend que de la distance \(r\). Le système possède donc une symétrie de rotation, et les coordonnées sphériques \((r,\theta,\varphi)\) sont naturelles. L’équation indépendante du temps pour le mouvement relatif est

\[ \left[ -\frac{\hbar^2}{2\mu}\nabla^2 -\frac{Ze^2}{4\pi\varepsilon_0r} \right]\psi(\mathbf r)=E\psi(\mathbf r). \tag{7}\]

2.1 Laplacien et moment cinétique

En coordonnées sphériques,

\[ \nabla^2 =\frac{1}{r^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) +\frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta} \left(\sin\theta\frac{\partial}{\partial\theta}\right) +\frac{1}{r^2\sin^2\theta}\frac{\partial^2}{\partial\varphi^2}. \tag{8}\]

La partie angulaire est reliée au carré du moment cinétique orbital :

\[ \widehat L^2 =-\hbar^2\left[ \frac{1}{\sin\theta}\frac{\partial}{\partial\theta} \left(\sin\theta\frac{\partial}{\partial\theta}\right) +\frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\varphi^2} \right]. \tag{9}\]

Le laplacien peut donc s’écrire

\[ \nabla^2 =\frac{1}{r^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) -\frac{\widehat L^2}{\hbar^2r^2}. \]

Comme \([\widehat H,\widehat L^2]=[\widehat H,\widehat L_z]=0\), on peut chercher des états propres communs sous la forme

\[ \boxed{ \psi_{n\ell m}(r,\theta,\varphi) =R_{n\ell}(r)Y_\ell^m(\theta,\varphi). } \tag{10}\]

2.2 Équation angulaire et nombres \(\ell\) et \(m\)

Les harmoniques sphériques satisfont

\[ \widehat L^2Y_\ell^m =\hbar^2\ell(\ell+1)Y_\ell^m, \tag{11}\]

\[ \widehat L_zY_\ell^m =\hbar mY_\ell^m. \tag{12}\]

La périodicité suivant l’angle azimutal impose

\[ Y(\theta,\varphi+2\pi)=Y(\theta,\varphi), \]

d’où un facteur \(e^{im\varphi}\) avec \(m\) entier. La régularité aux pôles \(\theta=0\) et \(\theta=\pi\) impose ensuite

\[ \ell=0,1,2,\ldots, \qquad m=-\ell,-\ell+1,\ldots,\ell. \tag{13}\]

Avec la convention de Condon–Shortley, les fonctions normalisées sont, pour \(m\ge0\),

\[ Y_\ell^m(\theta,\varphi) =(-1)^m \sqrt{\frac{2\ell+1}{4\pi} \frac{(\ell-m)!}{(\ell+m)!}} P_\ell^m(\cos\theta)e^{im\varphi}. \tag{14}\]

Les indices négatifs sont ensuite définis par

\[ Y_\ell^{-m}=(-1)^m\left(Y_\ell^m\right)^*. \]

Les premières sont

\[ Y_0^0=\frac{1}{\sqrt{4\pi}}, \]

\[ Y_1^0=\sqrt{\frac{3}{4\pi}}\cos\theta, \qquad Y_1^{\pm1}=\mp\sqrt{\frac{3}{8\pi}}\sin\theta\,e^{\pm i\varphi}, \]

\[ Y_2^0=\sqrt{\frac{5}{16\pi}}(3\cos^2\theta-1). \]

L’indice \(\ell\) fixe la norme du moment cinétique,

\[ |\mathbf L|=\hbar\sqrt{\ell(\ell+1)}, \]

tandis que \(m\) fixe sa projection mesurable suivant l’axe choisi,

\[ L_z=m\hbar. \]

Il ne faut pas interpréter ces relations comme un vecteur classique possédant simultanément trois composantes déterminées : dans l’état \(|\ell,m\rangle\), seules \(L^2\) et \(L_z\) sont certaines.

ImportantOrbitales complexes et orbitales réelles

Les états \(Y_\ell^m\) avec \(m\ne0\) sont généralement complexes. Les formes familières \(p_x\), \(p_y\), \(d_{xy}\) ou \(d_{x^2-y^2}\) sont des combinaisons linéaires réelles des états \(m\) et \(-m\). Elles ont la même énergie dans un potentiel coulombien, mais ne sont pas états propres de \(L_z\).

2.3 Équation radiale

En insérant Equation 10 dans Equation 7, puis en utilisant Equation 11, on obtient

\[ -\frac{\hbar^2}{2\mu} \frac{1}{r^2}\frac{\mathrm d}{\mathrm dr} \left(r^2\frac{\mathrm dR}{\mathrm dr}\right) +\frac{\hbar^2\ell(\ell+1)}{2\mu r^2}R -\frac{Ze^2}{4\pi\varepsilon_0r}R =ER. \tag{15}\]

La dérivée contenant \(r^2\) disparaît si l’on pose

\[ u(r)=rR(r). \tag{16}\]

En effet,

\[ R=\frac{u}{r}, \qquad r^2\frac{\mathrm dR}{\mathrm dr}=ru'-u, \qquad \frac{\mathrm d}{\mathrm dr}(ru'-u)=ru''. \]

Après multiplication par \(r\), l’équation devient une équation de Schrödinger unidimensionnelle sur \(r>0\) :

\[ \boxed{ -\frac{\hbar^2}{2\mu}\frac{\mathrm d^2u}{\mathrm dr^2} +V_{\mathrm{eff}}(r)u(r)=Eu(r), } \tag{17}\]

avec le potentiel effectif

\[ \boxed{ V_{\mathrm{eff}}(r) =-\frac{Ze^2}{4\pi\varepsilon_0r} +\frac{\hbar^2\ell(\ell+1)}{2\mu r^2}. } \tag{18}\]

Le second terme est la barrière centrifuge. Elle est absente pour les états \(s\) (\(\ell=0\)) et repousse les états de grand \(\ell\) loin du noyau. Les conditions physiques sont

\[ u(0)=0, \qquad u(r)\longrightarrow0\quad\text{lorsque }r\to\infty \]

pour un état lié normalisable.

3 Résoudre l’équation radiale et quantifier l’énergie

Nous cherchons maintenant les états liés, donc \(E<0\). Introduisons

\[ \kappa=\frac{\sqrt{-2\mu E}}{\hbar}>0, \qquad \rho=2\kappa r, \tag{19}\]

ainsi que le paramètre sans dimension

\[ \gamma =\frac{\mu Ze^2}{4\pi\varepsilon_0\hbar^2\kappa} =\frac{Z}{a_\mu\kappa}. \tag{20}\]

L’équation Equation 17 devient

\[ \frac{\mathrm d^2u}{\mathrm d\rho^2} +\left[ -\frac14+\frac{\gamma}{\rho} -\frac{\ell(\ell+1)}{\rho^2} \right]u=0. \tag{21}\]

3.1 Comportements asymptotiques

Lorsque \(\rho\to\infty\), les termes en \(1/\rho\) disparaissent et

\[ u''-\frac14u\simeq0. \]

Les solutions sont \(e^{\pm\rho/2}\). La normalisabilité élimine la solution croissante :

\[ u(\rho)\sim e^{-\rho/2}. \]

Près de l’origine, le terme centrifuge domine. Si \(u\sim\rho^s\), alors

\[ s(s-1)-\ell(\ell+1)=0, \]

d’où \(s=\ell+1\) ou \(s=-\ell\). La seconde solution diverge et ne satisfait pas \(u(0)=0\). Ainsi,

\[ u(\rho)\sim\rho^{\ell+1}. \]

Ces deux comportements suggèrent la factorisation

\[ u(\rho)=\rho^{\ell+1}e^{-\rho/2}v(\rho). \tag{22}\]

3.2 Série entière et condition de terminaison

En substituant Equation 22 dans Equation 21 et en simplifiant, on trouve

\[ \rho v''+(2\ell+2-\rho)v' +(\gamma-\ell-1)v=0. \tag{23}\]

Développons

\[ v(\rho)=\sum_{j=0}^{\infty}a_j\rho^j. \]

Après décalage des indices, le coefficient de \(\rho^j\) donne

\[ (j+1)(j+2\ell+2)a_{j+1} +(\gamma-\ell-1-j)a_j=0. \]

La relation de récurrence est donc

\[ a_{j+1} =\frac{j+\ell+1-\gamma} {(j+1)(j+2\ell+2)}a_j. \tag{24}\]

Si cette série ne s’arrête pas, son comportement asymptotique reconstruit un facteur \(e^{+\rho/2}\) qui annule la décroissance extraite et rend l’état non normalisable. Il faut donc qu’un numérateur s’annule pour un entier \(j=n_r\ge0\) :

\[ n_r+\ell+1-\gamma=0. \]

On définit le nombre quantique principal

\[ \boxed{ n=n_r+\ell+1=1,2,3,\ldots } \tag{25}\]

et la condition de quantification devient

\[ \gamma=n. \]

Comme \(\gamma=Z/(a_\mu\kappa)\),

\[ \kappa=\frac{Z}{na_\mu}. \]

Enfin, la définition de \(\kappa\) dans Equation 19 donne

\[ \boxed{ E_n =-\frac{\mu Z^2e^4} {2(4\pi\varepsilon_0)^2\hbar^2n^2} =-\frac{\mu c^2(Z\alpha)^2}{2n^2}. } \tag{26}\]

Pour un noyau infiniment lourd et \(Z=1\),

\[ E_n=-\frac{13{,}6057\ \mathrm{eV}}{n^2}. \]

Avec la masse réduite du véritable atome d’hydrogène, l’énergie d’ionisation fondamentale est légèrement plus faible, environ \(13{,}598\ \mathrm{eV}\).

ImportantOrigine de la quantification

L’énergie n’est pas quantifiée parce que l’électron suivrait certaines orbites autorisées. Elle l’est parce que seules certaines valeurs de \(E\) permettent à la solution radiale d’être à la fois régulière en \(r=0\) et normalisable à l’infini.

3.3 Fonctions radiales normalisées

La série terminée est un polynôme de Laguerre associé. En posant maintenant

\[ \rho=\frac{2Zr}{na_\mu}, \]

la solution normalisée est

\[ \boxed{ R_{n\ell}(r) =\left(\frac{2Z}{na_\mu}\right)^{3/2} \sqrt{\frac{(n-\ell-1)!}{2n(n+\ell)!}} e^{-\rho/2}\rho^\ell L_{n-\ell-1}^{2\ell+1}(\rho). } \tag{27}\]

Elle vérifie

\[ \int_0^\infty |R_{n\ell}(r)|^2r^2\,\mathrm dr=1. \]

Les trois premiers exemples utiles sont

\[ R_{10}(r)=2a_\mu^{-3/2}e^{-r/a_\mu}, \]

\[ R_{20}(r)=\frac{1}{2\sqrt{2}}\,a_\mu^{-3/2} \left(2-\frac{r}{a_\mu}\right)e^{-r/(2a_\mu)}, \]

\[ R_{21}(r)=\frac{1}{2\sqrt{6}}\,a_\mu^{-3/2} \frac{r}{a_\mu}e^{-r/(2a_\mu)}. \]

Pour un ion hydrogénoïde, il suffit de remplacer \(a_\mu\) par \(a_\mu/Z\) dans ces expressions.

3.4 Distribution radiale et nœuds

La quantité \(|R_{n\ell}(r)|^2\) n’est pas directement la densité de probabilité de la distance au noyau. Le volume d’une coquille sphérique de rayon \(r\) et d’épaisseur \(\mathrm dr\) contient le facteur \(r^2\mathrm dr\,\mathrm d\Omega\). Puisque les harmoniques sphériques sont normalisées,

\[ \int |Y_\ell^m|^2\,\mathrm d\Omega=1, \]

la probabilité de trouver l’électron entre \(r\) et \(r+\mathrm dr\) vaut

\[ \boxed{ \mathrm dP=P_{n\ell}(r)\,\mathrm dr, \qquad P_{n\ell}(r)=r^2|R_{n\ell}(r)|^2. } \tag{28}\]

En particulier, \(R_{10}(r)\) est maximal au noyau, mais \(P_{10}(0)=0\) car une coquille de rayon nul possède un volume nul. Pour l’état \(1s\),

\[ P_{10}(r)=\frac{4r^2}{a_\mu^3}e^{-2r/a_\mu}. \]

Sa dérivée s’annule pour

\[ \frac{\mathrm dP_{10}}{\mathrm dr} \propto 2r\left(1-\frac{r}{a_\mu}\right)e^{-2r/a_\mu}=0. \]

Le rayon le plus probable non nul est donc

\[ r_{\mathrm{mp}}=a_\mu. \tag{29}\]

Le polynôme \(L_{n-\ell-1}^{2\ell+1}\) possède \(n-\ell-1\) zéros positifs. Ainsi,

\[ N_{\mathrm{radial}}=n-\ell-1. \]

La partie angulaire possède \(\ell\) surfaces nodales au total. Le nombre total de nœuds est donc

\[ \boxed{ N_{\mathrm{total}}=(n-\ell-1)+\ell=n-1. } \tag{30}\]

Couche \(n\) \(1,2,3,\ldots\) Énergie et échelle radiale principale

La notation spectroscopique remplace \(\ell=0,1,2,3,\ldots\) par les lettres

\[ s,p,d,f,\ldots \]

Ainsi, \(3d\) signifie \(n=3\) et \(\ell=2\). Cette sous-couche contient cinq orbitales, car \(m=-2,-1,0,1,2\).

Pour une valeur fixée de \(n\), le nombre d’états spatiaux est

\[ g_n=\sum_{\ell=0}^{n-1}(2\ell+1)=n^2. \tag{31}\]

En incluant les deux projections du spin électronique, on obtient \(2n^2\) états à une particule. Ce nombre devient la capacité maximale d’une couche dans les atomes à plusieurs électrons, après application du principe de Pauli. L’atome d’hydrogène lui-même ne contient évidemment qu’un seul électron.

\(n\) Sous-couches permises Nombre d’orbitales spatiales
1 \(1s\) 1
2 \(2s\), \(2p\) \(1+3=4\)
3 \(3s\), \(3p\), \(3d\) \(1+3+5=9\)
4 \(4s\), \(4p\), \(4d\), \(4f\) \(1+3+5+7=16\)

Dans le modèle coulombien non relativiste, l’énergie Equation 26 ne dépend que de \(n\). Toutes les valeurs de \(\ell\) et \(m\) d’une même couche sont donc dégénérées. La dégénérescence en \(m\) vient de la symétrie de rotation ; la dégénérescence supplémentaire en \(\ell\) est propre au potentiel en \(1/r\) et est liée à une symétrie cachée décrite par le vecteur de Runge–Lenz.

4 Comprendre la géométrie des orbitales

Une orbitale hydrogénoïde est la fonction

\[ \psi_{n\ell m}(r,\theta,\varphi) =R_{n\ell}(r)Y_\ell^m(\theta,\varphi). \]

Sa densité de probabilité est

\[ \rho_{n\ell m}(\mathbf r) =|R_{n\ell}(r)|^2|Y_\ell^m(\theta,\varphi)|^2. \tag{32}\]

Une surface 3D d’orbitale ne représente ni une frontière matérielle ni la trajectoire de l’électron. C’est généralement une surface sur laquelle \(|\psi|\) possède une valeur fixée, ou un volume contenant une fraction choisie de la probabilité totale.

4.1 Nœuds et signe de la fonction d’onde

Un nœud radial est une sphère sur laquelle \(R_{n\ell}(r)=0\). Un nœud angulaire est un plan, un cône ou une autre surface sur laquelle \(Y_\ell^m=0\).

Les deux couleurs habituellement utilisées pour dessiner une orbitale indiquent les deux signes, ou plus généralement les deux phases, de la fonction d’onde. Elles ne représentent pas deux charges électriques différentes. La densité \(|\psi|^2\) est positive des deux côtés, mais le signe devient essentiel lorsque deux amplitudes interfèrent ou forment une liaison moléculaire.

Quelques exemples :

  • \(1s\) : aucun nœud, symétrie sphérique ;
  • \(2s\) : une sphère nodale, aucune surface angulaire ;
  • \(2p\) : aucun nœud radial, un plan nodal ;
  • \(3d\) : aucun nœud radial, deux nœuds angulaires ;
  • \(3p\) : une sphère nodale et un plan nodal.

Les orbitales réelles usuelles s’écrivent par exemple

\[ p_z\propto\cos\theta, \qquad p_x\propto\sin\theta\cos\varphi, \qquad p_y\propto\sin\theta\sin\varphi, \]

\[ d_{z^2}\propto3\cos^2\theta-1, \qquad d_{xy}\propto\sin^2\theta\sin(2\varphi), \]

\[ d_{x^2-y^2}\propto\sin^2\theta\cos(2\varphi). \]

Afficher le code Python 
def coupe_orbitale(n, l, type_orbitale, etendue, points=420):
    x = np.linspace(-etendue, etendue, points)
    z = np.linspace(-etendue, etendue, points)
    X, Zm = np.meshgrid(x, z)
    Ycoord = np.zeros_like(X)
    rayon = np.sqrt(X**2 + Ycoord**2 + Zm**2)
    theta = np.arccos(np.divide(
        Zm, rayon, out=np.ones_like(rayon), where=rayon > 1e-14
    ))
    phi = np.arctan2(Ycoord, X)
    psi = R_nl(n, l, rayon) * harmonique_reelle(type_orbitale, theta, phi)
    psi /= np.max(np.abs(psi))
    return x, z, psi

4.2 Valeurs moyennes et taille de l’atome

La taille d’une orbitale ne se résume pas à un rayon unique. On peut calculer différentes valeurs moyennes :

\[ \boxed{ \left\langle\frac1r\right\rangle_{n\ell} =\frac{Z}{a_\mu n^2}, } \tag{33}\]

\[ \boxed{ \langle r\rangle_{n\ell} =\frac{a_\mu}{2Z} \left[3n^2-\ell(\ell+1)\right], } \tag{34}\]

\[ \boxed{ \langle r^2\rangle_{n\ell} =\frac{a_\mu^2n^2}{2Z^2} \left[5n^2+1-3\ell(\ell+1)\right]. } \tag{35}\]

Pour l’état fondamental,

\[ r_{\mathrm{mp}}=a_\mu, \qquad \langle r\rangle_{100}=\frac32a_\mu, \qquad \sqrt{\langle r^2\rangle_{100}}=\sqrt{3}\,a_\mu. \]

Ces trois nombres répondent à trois questions différentes : position du maximum radial, distance moyenne et rayon quadratique moyen.

Pour un potentiel coulombien, le théorème du viriel donne

\[ 2\langle T\rangle=-\langle V\rangle. \]

Comme \(E=\langle T\rangle+\langle V\rangle\), il en résulte

\[ \boxed{ \langle T\rangle=-E_n, \qquad \langle V\rangle=2E_n. } \tag{36}\]

L’énergie totale est négative, bien que l’énergie cinétique moyenne soit positive. Il faut fournir l’énergie \(|E_n|\) pour ioniser l’atome depuis le niveau \(n\).

5 Spectre de l’hydrogène et transitions quantiques

Les états propres de l’hamiltonien sont stationnaires : leur densité de probabilité ne dépend pas du temps. Contrairement à une charge classique en orbite, un électron placé dans un état propre ne rayonne donc pas continuellement et ne s’effondre pas sur le noyau.

Une raie spectrale apparaît lorsqu’une interaction, généralement avec le champ électromagnétique, fait passer l’atome d’un niveau initial \(n_i\) à un niveau final \(n_f\). Pour une émission,

\[ n_i>n_f, \qquad h\nu=E_{n_i}-E_{n_f}>0. \tag{37}\]

En utilisant Equation 26,

\[ h\nu =\frac{\mu Z^2e^4}{2(4\pi\varepsilon_0)^2\hbar^2} \left(\frac{1}{n_f^2}-\frac{1}{n_i^2}\right). \]

Comme \(\nu=c/\lambda\), on obtient la formule de Rydberg :

\[ \boxed{ \frac{1}{\lambda} =R_\mu Z^2 \left(\frac{1}{n_f^2}-\frac{1}{n_i^2}\right), } \tag{38}\]

où

\[ R_\mu=\frac{\mu e^4}{8\varepsilon_0^2h^3c}. \]

Pour l’hydrogène, \(R_\mathrm H\simeq1{,}0968\times10^7\ \mathrm{m}^{-1}\). La dépendance en masse réduite explique pourquoi l’hydrogène et le deutérium possèdent des raies légèrement décalées.

5.2 Règles de sélection dipolaires

La conservation de l’énergie indique où se trouve une raie, mais pas si elle est intense ou même permise. Dans l’approximation dipolaire électrique, l’amplitude d’une transition contient

\[ \mathbf d_{fi} =-e\langle n_f\ell_fm_f|\widehat{\mathbf r}| n_i\ell_im_i\rangle. \tag{39}\]

L’opérateur position possède la parité impaire et se transforme comme un objet de moment cinétique un. Les propriétés angulaires imposent

\[ \boxed{ \Delta\ell=\pm1, \qquad \Delta m=0,\pm1. } \tag{40}\]

La polarisation du photon précise quelle valeur de \(\Delta m\) est réalisée. En l’absence d’interaction agissant sur le spin,

\[ \Delta s=0. \]

Une transition qui ne respecte pas ces règles est interdite au niveau dipolaire électrique, mais elle peut encore se produire beaucoup plus lentement par un mécanisme d’ordre supérieur. Ainsi, l’état \(2s\) ne peut pas se désexciter vers \(1s\) par émission d’un seul photon dipolaire ; il se désintègre principalement par émission de deux photons.

ImportantUne transition n’est pas une trajectoire

Entre deux mesures, la mécanique quantique ne décrit pas l’électron comme une petite bille sautant le long d’un chemin défini entre deux couches. L’interaction fait évoluer l’état quantique ; l’émission d’un photon corrèle finalement l’atome au champ électromagnétique avec une énergie \(E_i-E_f\).

5.3 Contrôle numérique de l’équation radiale

On peut retrouver les niveaux sans employer leur expression analytique. En unités atomiques, discrétisons Equation 17 sur une grille \(r_j=j\Delta r\). La dérivée seconde centrée est

\[ u''(r_j)\simeq \frac{u_{j+1}-2u_j+u_{j-1}}{\Delta r^2}. \]

L’hamiltonien devient une matrice tridiagonale dont les valeurs propres négatives approchent les états liés.

Afficher le code Python 
r_max = 55.0
N_grille = 320
dr = r_max / (N_grille + 1)
r = dr * np.arange(1, N_grille + 1)

def spectre_radial_numerique(l):
    diagonale = 1/dr**2 - 1/r + l*(l+1)/(2*r**2)
    hors_diagonale = -np.ones(N_grille - 1) / (2*dr**2)
    H = (np.diag(diagonale)
         + np.diag(hors_diagonale, 1)
         + np.diag(hors_diagonale, -1))
    energies, vecteurs = np.linalg.eigh(H)
    masque = energies < 0
    return energies[masque], vecteurs[:, masque]

5.4 Ce que le modèle de Schrödinger ne sépare pas

La formule Equation 26 est remarquablement précise, mais le spectre réel possède une structure plus fine.

Effet Origine physique Conséquence principale
Masse réduite Mouvement du noyau Décalage isotopique global
Structure fine Relativité, couplage spin–orbite, terme de Darwin Dépendance en \(n\) et en \(j\)
Décalage de Lamb Fluctuations quantiques du champ électromagnétique Séparation de \(2S_{1/2}\) et \(2P_{1/2}\)
Structure hyperfine Couplage entre spins électronique et nucléaire Raie de \(21\ \mathrm{cm}\) de l’hydrogène
Effet Zeeman Champ magnétique extérieur Levée de dégénérescence selon \(m\)
Effet Stark Champ électrique extérieur Mélange des états et déplacement des niveaux

À l’ordre dominant en \(Z\alpha\), la structure fine peut être résumée par

\[ \Delta E_{nj}^{\mathrm{fine}} =-\frac{\mu c^2(Z\alpha)^4}{2n^4} \left(\frac{n}{j+1/2}-\frac34\right). \tag{41}\]

Elle lève une partie de la dégénérescence en \(\ell\), mais la théorie de Dirac conserve encore l’égalité entre certains états, notamment \(2S_{1/2}\) et \(2P_{1/2}\). Le décalage de Lamb, expliqué par l’électrodynamique quantique, lève cette dernière coïncidence.

NotePourquoi l’hydrogène reste un banc d’essai fondamental

Chaque amélioration de la théorie peut être comparée à des fréquences mesurées avec une précision exceptionnelle. L’hydrogène teste ainsi la mécanique quantique, l’électrodynamique quantique, les constantes fondamentales, la taille du proton et la recherche de faibles interactions nouvelles.

7 Conclusion

L’atome d’hydrogène rassemble dans un seul problème les idées importantes de la mécanique quantique à trois dimensions.

Propriété Résultat
Hamiltonien relatif \(\widehat H=-\dfrac{\hbar^2}{2\mu}\nabla^2-\dfrac{Ze^2}{4\pi\varepsilon_0r}\)
Séparation \(\psi_{n\ell m}=R_{n\ell}Y_\ell^m\)
Nombres quantiques \(n\ge1\), \(0\le\ell\le n-1\), \(-\ell\le m\le\ell\)
Énergie \(E_n=-\dfrac{\mu c^2(Z\alpha)^2}{2n^2}\)
Dégénérescence spatiale \(g_n=n^2\)

Transition dipolaire \(\Delta\ell=\pm1\), \(\Delta m=0,\pm1\)

La logique complète peut se lire comme une chaîne : la symétrie sphérique sépare les variables ; la régularité quantifie le moment cinétique ; la normalisabilité quantifie l’énergie ; les nombres quantiques organisent les orbitales ; enfin, les différences d’énergie et les éléments de matrice déterminent le spectre observé.

TipMéthode de lecture d’une orbitale

Pour interpréter une orbitale \(n\ell m\), procéder toujours dans cet ordre :

  1. lire \(n\) pour connaître l’énergie et l’échelle radiale ;
  2. lire \(\ell\) pour connaître \(L^2\) et le nombre de nœuds angulaires ;
  3. lire \(m\) pour identifier la projection \(L_z\) dans la base complexe ;
  4. compter \(n-\ell-1\) nœuds radiaux ;
  5. distinguer le signe de \(\psi\) de la densité positive \(|\psi|^2\).
